# 지환이의 신나는 놀이방

공룡·자동차·기차·동물과 놀면서 배우는 놀이 17가지가 들어 있어요.
**하나의 웹앱**으로 PC, 안드로이드, 아이패드에서 모두 쓰고, 안드로이드에서는 **앱 파일(APK)** 로도 설치할 수 있어요. 모두 무료예요.

| 쓰는 곳 | 방법 | 필요한 것 |
|---|---|---|
| PC (웹) | 인터넷 주소로 열기 | 웹앱 올리기(1단계) |
| 아이패드 | 사파리에서 "홈 화면에 추가" | 웹앱 올리기(1단계) |
| 안드로이드 | APK 설치 (또는 크롬에서 앱 설치) | APK 만들기(2단계) |

폴더 구성: `docs/` = 웹앱 파일(글꼴·아이콘·오프라인 저장 포함), `android/` = 안드로이드 앱 프로젝트, `.github/workflows/` = 자동 빌드 설정.

---

## 1단계. 웹앱 올리기 (GitHub Pages, 무료)

1. GitHub(github.com)에 가입해요 (무료).
2. 새 저장소(Repository)를 만들어요. 이름 예: `jihwan-playroom`, **Public(공개)** 으로 만들어요.
3. 이 폴더의 **모든 파일**을 저장소에 올려요. 숨김 폴더 `.github`가 빠지기 쉬워서 **GitHub Desktop** 이나 `git`으로 올리는 걸 추천해요.
   - 웹 화면에서 올릴 때 `.github/workflows/build-apk.yml`이 안 올라가면: 저장소에서 **Add file → Create new file**, 이름 칸에 `.github/workflows/build-apk.yml` 을 그대로 입력하고 파일 내용을 붙여 넣어요.
4. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/docs** 로 고르고 Save를 눌러요.
5. 1~2분 뒤 `https://내아이디.github.io/jihwan-playroom/` 주소가 생겨요. 이 주소가 웹앱이에요.

> 공개 저장소라서 주소를 아는 사람은 누구나 열 수 있어요. 이 앱에는 이름, 사진 같은 개인정보가 없고, 모은 별은 각자 기기에만 저장돼요.

### PC에서 쓰기
위 주소를 크롬이나 엣지로 열어요. 주소창 오른쪽의 **설치(앱으로 열기)** 아이콘을 누르면 창으로 열리는 앱처럼 쓸 수 있어요.

### 아이패드에서 쓰기
1. **사파리**로 위 주소를 열어요 (크롬이 아니라 사파리예요).
2. 아래(또는 위)의 **공유 버튼 → 홈 화면에 추가**를 눌러요.
3. 홈 화면의 **지환이 놀이방** 아이콘으로 열어요. 한 번 열어 두면 인터넷이 없어도 열려요.
4. 소리가 안 나면 무음 스위치(또는 제어 센터의 무음)를 끄고 볼륨을 올려요.

---

## 2단계. 안드로이드 APK 만들기 (GitHub Actions, 무료)

1. 저장소의 **Actions** 탭을 열어요. 처음이면 "워크플로를 사용하시겠습니까?"가 나오면 허용해요.
2. 왼쪽에서 **APK 만들기**를 고르고 **Run workflow**를 눌러요.
3. 5~10분쯤 걸려요. 초록 체크가 뜨면 저장소 오른쪽의 **Releases**에서 `jihwan-playroom.apk`를 받아요.
   - Releases 링크는 로그인 없이 받을 수 있어서, 가족에게 링크를 카톡으로 보내 줄 수 있어요.

### 폰·태블릿에 설치하기
1. 받은 `jihwan-playroom.apk`를 눌러요.
2. "출처를 알 수 없는 앱" 경고가 나오면 **설정에서 이 브라우저(또는 파일 앱)의 설치를 허용**해요.
3. 설치가 끝나면 **지환이 놀이방** 아이콘이 생겨요.

가장 쉬운 방법이 필요하면, 안드로이드 크롬에서 웹앱 주소를 열고 ⋮ 메뉴의 **앱 설치(또는 홈 화면에 추가)** 를 눌러도 앱처럼 쓸 수 있어요.

---

## 업데이트할 때
- 웹앱을 고쳤다면 `docs/sw.js` 맨 위의 `VERSION = 'playroom-v1'`을 `v2`, `v3`… 로 올려서 저장소에 올려요. 안 올리면 예전 화면이 계속 보일 수 있어요.
- APK는 위 2단계를 다시 실행해요. 같은 서명으로 만들어지고 버전 번호가 자동으로 커져서, 설치된 앱 위에 그대로 덮어 설치돼요(모은 별도 유지돼요).

## 문제가 생기면
- **Actions가 빨간색으로 끝나요**: 실패한 단계를 눌러 마지막 오류 줄을 복사해서 알려 주세요.
- **APK 설치가 막혀요**: 설정 → 보안(또는 앱) → "출처를 알 수 없는 앱 설치"에서 방금 쓴 앱(크롬, 파일 등)을 허용해요.
- **소리(목소리)가 안 나요**: 폰의 무음 모드를 끄고 미디어 볼륨을 올려요. 한국어 음성이 없는 기기는 설정 → 일반 관리 → 텍스트 음성 변환(TTS)에서 한국어 음성 데이터를 받아야 해요.
- **PC에서 목소리가 안 나요**: 브라우저 탭의 소리 차단을 풀어요. 화면을 한 번 눌러야 소리가 시작돼요.

## 알아둘 점
- 이 APK는 스토어에 올리는 정식 버전이 아니라 **직접 설치하는 가족용**이에요. Play 스토어 등록은 유료(개발자 등록비)이고 신규 개인 계정은 추가 테스트 절차가 있어요.
- 아이패드용 앱스토어 앱은 만들지 않았어요(연 99달러). 대신 웹앱을 홈 화면에 추가해서 써요.
- 모은 별과 친구 기록은 **각 기기 안에만** 저장돼요. 기기끼리 합쳐지지 않아요.
