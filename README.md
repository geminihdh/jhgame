# 지환이의 신나는 놀이방

**한글 나라**(자음+모음이 만나 글자가 되는 놀이, 낱말·문장 만들기)와 **ABC 나라**(A~Z 그림 카드, 낱말·문장 만들기), 모두 14가지 놀이가 들어 있어요. 단계(Lv 1~5)는 아이가 잘하면 자동으로 올라가요. 하나의 웹앱으로 **PC, 안드로이드, 아이패드**에서 쓰고, 안드로이드에서는 **설치 파일(APK)** 로도 설치해요. 모두 무료예요.

폴더 구성: `docs/` 웹앱 파일(글꼴·아이콘·오프라인 저장 포함) / `assets/` 앱 아이콘·시작 화면 / `scripts/`, `signing/`, `.github/` 안드로이드 자동 빌드용 파일. (안드로이드 프로젝트 폴더는 GitHub가 자동으로 만들어서 여기에 없어요.)

> 아래 메뉴 이름은 GitHub 화면의 영어 글자 그대로 적었어요. GitHub 화면이 바뀌어서 조금 다르면, 비슷한 이름의 메뉴를 찾아 보세요.

## 먼저 읽어 주세요: 이미 올려 두셨다면 (업데이트 방법)

예전 놀이방을 GitHub에 올려 두셨다면 **처음부터 다시 하지 않아도 돼요.** 아래 파일 5개만 바꿔 올리면 돼요. (웹 주소와 안드로이드 설치 파일이 자동으로 새로 만들어져요.)

1. 이 zip을 PC에서 압축 해제해요.
2. GitHub의 저장소(예: `jhgame`)를 열고 **Add file → Upload files** 를 눌러요.
3. 압축 푼 폴더의 **`docs` 폴더 안에 있는 항목을 모두 선택**해서 끌어다 놓아요. (`index.html`, `sw.js`, `manifest.webmanifest`, `fonts` 폴더가 덮어써져요.) `docs` 폴더 째 올려도 같은 위치에 덮어써져요.
4. 아래 **Commit changes** 를 누르면 끝이에요. 웹 주소는 1~2분, **Actions** 탭의 "APK 만들기"는 5~10분 뒤에 새 버전이 돼요.
5. 이미 설치한 앱은 **새 APK를 위에 덮어서 설치**하면 돼요. 웹앱(PC·아이패드)은 주소를 새로고침하면 새 버전이 보여요. (안 바뀌면 한 번 더 새로고침하거나 홈 화면 아이콘을 지웠다가 다시 추가해요.)

> **목소리가 기계 같을 때**: 놀이방 앱의 ⚙️ 부모님 설정 → **목소리** 에서 "★온라인" 또는 "network" 이 붙은 한국어 목소리를 고르고 속도·높낮이를 조절해 보세요. 기기마다 설치 방법도 그 화면에 적어 놨어요.

## A. 준비

1. 이 zip 파일을 **PC에서 압축 해제**해요.
2. 압축 푼 폴더 안에 `.github`, `assets`, `docs`, `scripts`, `signing` 폴더와 `README.md`, `package.json` 등이 모두 있는지 확인해요. (Mac에서 `.github`가 안 보이면 Finder에서 `Command + Shift + .` 을 눌러요.)

## B. GitHub 가입하고 저장소 만들기

3. 크롬에서 **github.com** 에 가서 **Sign up** 을 눌러 가입해요. 이메일, 비밀번호, 사용자 이름(영문)을 넣고, 이메일로 온 인증 번호를 입력해요. **사용자 이름이 나중에 웹앱 주소가 돼요.** (`사용자이름.github.io`)
4. 로그인한 뒤 오른쪽 위의 **+** 버튼 → **New repository** 를 눌러요.
5. 이렇게 입력해요.
   - **Repository name**: `jihwan-playroom`
   - **Public** 을 선택해요. (무료 웹 주소(GitHub Pages)는 Public 저장소에서 쓸 수 있어요.)
   - 나머지(Add a README file, .gitignore 등)는 **모두 체크하지 않아요.**
   - 아래의 초록색 **Create repository** 를 눌러요.

## C. 파일 올리기

6. 방금 만든 빈 저장소 화면에서 **uploading an existing file** 링크를 눌러요. (링크가 안 보이면 **Add file → Upload files**.)
7. 압축 푼 폴더를 열고 **안의 모든 항목을 선택(Ctrl + A)** 해서, 브라우저의 "Drag files here" 영역에 **끌어다 놓아요.** 폴더 째 올라가서 폴더 구조가 그대로 유지돼요. 파일은 모두 22개이고, 한 번에 100개까지 올릴 수 있어서 한 번에 올려도 돼요.
8. 업로드가 끝나면 목록에서 아래가 보이는지 확인해요.
   - `.github/workflows/build-apk.yml`
   - `docs/index.html`
   - `scripts/prepare-android.mjs`
   - `signing/jihwan-playroom.keystore`

   **`.github` 폴더가 빠졌다면**: 저장소 화면에서 **Add file → Create new file** 을 누르고, 이름 칸에 `.github/workflows/build-apk.yml` 을 그대로 입력해요(`/`를 입력하면 폴더가 만들어져요). 아래 큰 입력 칸에 zip 안의 같은 파일 내용을 붙여넣고 **Commit changes** 를 눌러요.
9. 화면 아래 **Commit changes** 칸에서 메시지는 `처음 올림` 처럼 아무거나 쓰고, **Commit directly to the `main` branch** 를 선택한 다음 초록색 **Commit changes** 버튼을 눌러요.

## D. 웹앱 주소 만들기 (PC·아이패드용)

10. 저장소 위쪽 탭에서 **Settings** 를 눌러요. (탭이 안 보이면 `...` 또는 드롭다운을 눌러 Settings를 찾아요.)
11. 왼쪽 메뉴의 **Code and automation** 아래에서 **Pages** 를 눌러요.
12. **Build and deployment** 의 **Source** 에서 **Deploy from a branch** 를 골라요.
13. 그 아래 **Branch** 드롭다운에서 **main**, 옆의 폴더 드롭다운에서 **/docs** 를 골라 **Save** 를 눌러요.
14. 1~2분 뒤 같은 화면 위쪽에 **Your site is live at https://사용자이름.github.io/jihwan-playroom/** 이 나와요. 이 주소가 웹앱이에요. 처음에 "404"가 나오면 몇 분 기다렸다가 새로고침해요.

## E. 안드로이드 설치 파일(APK) 받기

15. 파일을 올리면 APK 만들기가 **자동으로 시작돼요.** 저장소 위쪽 **Actions** 탭 → 왼쪽의 **APK 만들기** 를 눌러요. 맨 위 실행 줄의 표시는 이래요: 노란 점 = 만드는 중, 초록 체크 = 성공, 빨간 X = 실패. 5~10분 걸려요.
    - 자동으로 시작되지 않았다면: **Actions → APK 만들기 → 오른쪽의 Run workflow → 초록색 Run workflow 버튼**. (Actions가 꺼져 있다는 안내가 나오면 **I understand my workflows, go ahead and enable them** 을 눌러요.)
    - 파일을 올리는 도중에 시작돼서 실패했다면, 다 올린 뒤에 위 방법으로 다시 실행해요.
16. 초록 체크가 뜨면 저장소 첫 화면(**Code** 탭)으로 가요. 오른쪽 사이드바의 **Releases** 아래 가장 위의 **지환이의 신나는 놀이방 APK (빌드 N)** 을 눌러요.
17. 페이지 아래쪽 **Assets** 에 **jihwan-playroom.apk** 가 있어요. **이 페이지의 주소를 가족에게 카톡으로 보내면** 로그인 없이 받을 수 있어요.

## F. 기기별로 설치하기

### 안드로이드 폰·태블릿
1. 폰의 크롬으로 위 Releases 주소를 열고 **jihwan-playroom.apk** 를 눌러요.
2. "이 유형의 파일은 기기에 해를 끼칠 수 있습니다"가 나오면 **확인(또는 다운로드)** 을 눌러요.
3. 다운로드가 끝나면 알림이나 **내 파일**의 다운로드 폴더에서 `jihwan-playroom.apk` 를 눌러요.
4. "출처를 알 수 없는 앱" 안내가 나오면 **설정** → **이 출처 허용**(크롬 또는 내 파일)을 켜고 뒤로 돌아와 **설치** 를 눌러요.
5. 삼성 폰에서 설치가 계속 막히면 설정에서 **자동 차단(Auto Blocker)** 을 검색해 잠시 꺼요. 설치 뒤에 다시 켜도 돼요.
6. 설치가 끝나면 **지환이 놀이방** 아이콘이 생겨요.

(더 간단한 방법: 안드로이드 크롬에서 웹앱 주소를 열고 오른쪽 위 ⋮ 메뉴의 **앱 설치(또는 홈 화면에 추가)** 를 눌러도 앱처럼 쓸 수 있어요.)

### 아이패드
1. **사파리**로 웹앱 주소를 열어요. (크롬이 아니라 사파리예요.)
2. 화면 위쪽(또는 아래쪽)의 **공유 버튼(네모에 위쪽 화살표)** 을 눌러요.
3. 메뉴를 내려서 **홈 화면에 추가** 를 누르고 이름을 확인한 뒤 **추가** 를 눌러요.
4. 홈 화면의 **지환이 놀이방** 아이콘으로 열어요. 한 번 열어 두면 인터넷이 없어도 열려요.
5. 소리가 안 나면 아이패드의 무음 설정을 끄고 볼륨을 올려요.

### PC
1. 크롬이나 엣지로 웹앱 주소를 열어요.
2. 주소창 오른쪽에 **설치** 아이콘이 보이면 눌러요. 별도 창으로 열리는 앱처럼 쓸 수 있어요. (아이콘이 없으면 그냥 주소를 즐겨찾기에 넣어 쓰세요.)
3. 목소리는 화면을 한 번 클릭한 뒤부터 나요.

## G. 나중에 고치고 싶을 때

- **웹앱을 고쳤을 때**: 저장소에서 **Add file → Upload files** 로 고친 파일을 같은 위치(`docs/…`)에 올려 덮어써요. 그리고 `docs/sw.js` 파일을 열어 오른쪽 위 **연필(Edit this file)** 아이콘을 눌러 맨 위 `playroom-v1` 을 `playroom-v2` 처럼 바꾸고 **Commit changes** 를 눌러요. 안 바꾸면 예전 화면이 계속 보일 수 있어요.
- **APK를 새로 만들 때**: 파일을 올리면 자동으로 새 APK가 만들어져요. 서명이 같고 버전 번호가 커져서, 설치된 앱 위에 그대로 덮어 설치돼요(모은 별도 그대로예요).

## H. 문제가 생기면

- **Actions가 빨간 X로 끝나요**: 실패한 실행을 눌러 빨간 X가 있는 단계를 열고, 마지막 오류 몇 줄을 복사해서 알려 주세요.
- **웹앱 주소가 404예요**: Settings → Pages에서 Branch가 `main`, 폴더가 `/docs` 인지 확인하고 몇 분 기다려요. 저장소가 Public인지도 확인해요.
- **Releases에 APK가 없어요**: Actions 탭에서 가장 위 실행이 초록 체크인지 확인해요.
- **소리(목소리)가 안 나요**: 무음 모드를 끄고 미디어 볼륨을 올려요. 한국어 음성이 없는 안드로이드는 설정에서 텍스트 음성 변환(TTS)의 한국어 음성 데이터를 받아야 해요.

## 알아둘 점
- 웹앱 주소는 공개라서 주소를 아는 사람은 열 수 있어요. 개인정보가 없고, 모은 별은 각 기기 안에만 저장돼요. 기기끼리 합쳐지지는 않아요.
- 이 APK는 스토어에 올리는 정식 버전이 아니라 **직접 설치하는 가족용**이에요. 서명용 키 파일이 이 저장소에 공개돼 있어요. 가족끼리 쓰는 용도라면 괜찮지만, Play 스토어에 올릴 때는 새 키를 만들어야 해요.
- 아이패드용 앱스토어 앱은 만들지 않았어요(연 99달러). 웹앱을 홈 화면에 추가해서 써요.
